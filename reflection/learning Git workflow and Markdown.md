### What are the four working areas in Git?

Working directory, Staging area, Local repository, Remote repository

### Why does Git have a Staging Area instead of moving every change directly into the Local Repository?

Staging area is a place for testing

### What is the difference between git add, git commit, and git push?

- git add is to tell git I'm finished, needs to put the file together
- git commit is to save the file on your computer
- git push is to upload the file to the remote server
