## 1.Explain this workflow in your own words:
### clone → create branch → create index.js → add → commit → push

clone is to copy others repository to your local

create branch is to create your own workspace isolate with others so you dont mess up with the main project

create index.js is writing the code

add is to tell Git you want to put it in Staging Area

commit is to save it in your local

push is to upload to the remote repository
