## Part A — The Four Working Areas

> [ Working Directory ]
> 
>        │
> 
>        │  git add
> 
>        ▼
> 
> [ Staging Area ]
> 
>        │
> 
>        │  git commit
> 
>        ▼
> 
> [ Local Repository ]
> 
>        │
> 
>        │  git push
> 
>        ▼
> 
> [ Remote Repository ]

> ### git add
> 
> What it does: Moves file from your workspace into the staging area
> 
> Where the change starts: Working Directory
> 
> Where the change goes: Staging Area
> 
> When to use it: When you finished for edit files

> ### git commit
> 
> What it does: Save the file permanently on your computer
> 
> Where the change starts: Staging Area
> 
> Where the change goes: Local Repository
> 
> When to use it: When you done with testing and fixed the bug

> ### git add
> 
> What it does: Upload the file from your computer to remote server
> 
> Where the change starts: Local Repository
> 
> Where the change goes: Remote Repository
> 
> When to use it: When you want collaborate with others


## Part B — GitHub Markdown

### Headings

add "#" before the text

> Example: 
> ### Title

the maximum of dash is up to 6

Use case: to make long text clearly for understand

### Bold and italic text

**text** for bold and *text* for italic

> Example:
> this is a **Important** message

Use case: highlights the key word

### Lists

add "-" before the text

> Example: 
> - List of something

Use case: List bullet point

### Links

"[Text]" + "(Link)"

> Example:
> [Google it](google.com)

Use case: let user connect to website directly

### Images

"!" + "[Text]" + "(Path to image)"

> Example:
> ![Map]("C:\Users\Admin\Pictures\1.jpg")

Use case: import the image in the file

### Code and code blocks

"`" before and after the code

> Example:
> `code 112233`

Use case: show the code to user
