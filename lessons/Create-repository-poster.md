## 1. Introduce to repository

Repository is a digital store that developer put their code in it

## 2. Creating a repository

How to create a repository in Github:

1. Click New at upper right corner

2. Give your repository a name and description

3. Configure about it such as visibility, add README file, add .gitignore and licenses

4. Last step is to click the green button shows create repository

## 3. What are licenses

Licenses is a things to tell others what they can and what they cannot do with your code such as copyright

## 4. Forking a repository

Forking a repository means copy other's repository and work on it in your own area

you can ask for the repository owner to merge it

## 5. What is a .gitignore file

Tells Git what files should to ignore

This is to ensure some file are not tracked by Git
